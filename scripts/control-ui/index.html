최신 버전은 호환성을 보장하지 않습니다. Caveman 엔진은 선택한 CLI 설치기가 결정합니다. Codex CLI는 서버 Pod의 로그인 도구이며, Windows Codex 데스크톱 앱은 여기서 업데이트하지 않습니다. 업데이트는 이 서버를 공유하는 모든 PC에 영향을 줍니다. 완료 후 이 PC와 같은 Pod의 등록 PC를 동기화하며, 꺼진 PC는 나중에 다시 동기화하세요.
